# Prem-professional-portfolio

Static site: HTML + CSS + JavaScript with Three.js (loaded from jsDelivr). No build step.

## Run locally
    python3 -m http.server 5173
    # open http://localhost:5173

## Edit content
All text, projects, certificates and links live in `js/data.js`.
Certificate files go in `assets/certs/`, with a thumbnail at `assets/thumbs/<id>.jpg`.

## Deploy (GitHub Pages)
Push this folder to a repo, then Settings → Pages → Deploy from branch `main` / root.
